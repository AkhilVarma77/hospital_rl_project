# Predictive Attention-Based Multi-Agent Reinforcement Learning for Dynamic Hospital Resource Management

Academic simulation project. **All data are synthetic** (generated by a simulator with assumed parameters); nothing here describes a real hospital.

Three cooperating reinforcement-learning agents (bed allocation, doctor/patient scheduling, operating-room scheduling) share one simulated hospital. The project compares rule-based baselines, independent PPO, PPO with attention-based communication, PPO with demand forecasting, and DQN.

## What the experiments showed (short version)

In our runs (3 training seeds x 40 iterations, 7 scenarios, 5 evaluation seeds, untuned hyperparameters):
- learned PPO agents are about as good as the rule-based baselines on waiting time, slightly better on emergency response delay, and clearly **worse on emergency surgery waiting**;
- they submit about 17-18 conflicting (invalid) actions per episode, which the baselines avoid by construction;
- DQN was worse than PPO on waiting, throughput and untreated patients;
- **no evidence** that attention-based communication or demand forecasting helps; the attention variant was unstable across seeds.

These are results of short, untuned runs on one simulator. See the report for the caveats.

## Setup (Windows, PowerShell)

```
python -m venv venv
venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python -m pytest -q          # 191 tests
```
CPU only; no GPU or paid service is needed.

## Main commands

```
python scripts/generate_data.py --scenario all                 # synthetic data (CSV) for every scenario
python scripts/run_baseline.py --scenario all --num-seeds 5    # FCFS and severity baselines
python scripts/run_training.py --algo ppo --scenario normal --iterations 40
python scripts/run_training.py --algo dqn --scenario normal --iterations 40
python scripts/run_training.py --algo comm_ppo --comm-mode attention --scenario normal --iterations 40
python scripts/run_forecaster.py                               # LSTM + moving-average forecaster
python scripts/run_all_experiments.py --profile smoke          # pipeline check (minutes)
python scripts/run_all_experiments.py --profile default        # main experiment (about 2 hours, resumable)
python scripts/run_evaluation.py --scenario normal --model ppo ppo <checkpoint.pt>
python scripts/build_dashboard.py --models                     # rebuild docs/dashboard.html from your own results and checkpoints
python scripts/export_dashboard_data.py --scenario high_demand --policy severity --out replay.json   # one replay to load into the dashboard
```
Outputs: `results/logs/` (single training runs), `results/experiments/<profile>/` (tables, figures, per-run logs and checkpoints), `results/forecaster/`, `results/tables/`.
